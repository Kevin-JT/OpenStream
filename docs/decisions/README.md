# Architecture Decision Records

This directory contains Architecture Decision Records (ADRs) for significant technical decisions.

## Format

Each ADR should follow the format:
- Title
- Status (Proposed/Accepted/Rejected/Deprecated/Superseded)
- Context
- Decision
- Consequences

## Current Decisions

None recorded yet. Decisions will be documented as they are made during the project phases.

## Process

1. Propose a decision in a new ADR file
2. Discuss and review
3. Update status to Accepted or Rejected
4. Reference in relevant documentation
